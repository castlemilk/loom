# Loom: interactive graph visualization in TypeScript

[Open the canonical Loom page](https://castlemilk.github.io/loom/)

Loom is an MIT-licensed TypeScript SDK for interactive network diagrams and knowledge graphs. Use its WebGL2 renderer to draw and explore nodes and links or its headless editor to preview and apply revision-checked commands.

Graph Studio is the visual editor and demo application. Graph MCP is a separate read-only server for searching graph data, tracing paths, and retrieving indexed source evidence when available. The public Pages site hosts documentation and demos, not an authenticated MCP endpoint.
