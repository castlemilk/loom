Connect a client

Use Node.js 22.14 or later. Add this configuration to a client that supports local MCP servers over stdio, then reopen its connection.

Start with Wikispeedia, the knowledge console or either curated Wikipedia graph. For your own data, download scene.json from Studio and choose My Studio export.

Try asking “How does Music connect to Sound in Wikispeedia? Show me the source.”

Available queries

list_graphs
Discover graph IDs, sizes and attribution.
search_nodes
Find nodes by name, ID, section or subject.
get_node
Read the original fields and count incoming and outgoing links.
get_neighbors
Page through the articles around a node in either direction.
get_connection
Inspect parallel edges and retrieve archived cross-topic evidence where available.
find_path
Trace a shortest directed path within a chosen number of hops.

Clients can also read loom://graphs/catalog and the node resource URI returned by each search. Read the MCP guide as Markdown.

To build an editing agent, use the SDK’s graph editing guide.
