Build with Loom

Mount the TypeScript engine on a sized canvas. The wire model uses the same nodes and links in the live preview and in the studio.

TypeScript API ↗Download package ↓
Mount the wire modelwire-model.json ↓
import { createGraph } from 'loom-core'
import model from './wire-model.json'

const canvas = document.querySelector('canvas')!
createGraph(canvas, { ...model, mode: 'cloud' })
