# Node graph library for TypeScript

[Open the canonical Loom page](https://castlemilk.github.io/loom/node-graph/)

Loom is an open-source node graph library for building interactive node-link diagrams in JavaScript or TypeScript. Use the WebGL2 renderer to explore relationships, or use the headless editor to preview and apply changes against a known graph revision.

## Public examples

### Read the Canva relationship graph

Inspect the example’s founder and portfolio relationships without opening the canvas. Each row links to its recorded evidence.

[Open example](https://castlemilk.github.io/loom/studio/cards/) · [Read Markdown](https://castlemilk.github.io/loom/studio/cards/index.md) · [Get JSON](https://castlemilk.github.io/loom/examples/around-canva.json)

### Follow a Bauhaus article into Studio

Open the HTML article index, follow a named article into Studio, or read the same nodes and links as JSON.

[Open example](https://castlemilk.github.io/loom/examples/bauhaus/) · [Read Markdown](https://castlemilk.github.io/loom/examples/bauhaus/index.md) · [Get JSON](https://castlemilk.github.io/loom/examples/bauhaus.json)

### Explore the Outer Solar System graph

Browse the article index in HTML or read the JSON. Choose an article to open the surrounding graph.

[Open example](https://castlemilk.github.io/loom/examples/outer-solar-system/) · [Read Markdown](https://castlemilk.github.io/loom/examples/outer-solar-system/index.md) · [Get JSON](https://castlemilk.github.io/loom/examples/outer-solar-system.json)

### Trace Music to Sound

Follow the archived Music article’s hyperlink to Sound. The interactive permalink opens that exact connection.

[Open example](https://castlemilk.github.io/loom/studio/wikispeedia/?connections=music,science&edge=74%3A2863) · [Read Markdown](https://castlemilk.github.io/loom/studio/wikispeedia/index.md) · [Get JSON](https://castlemilk.github.io/loom/examples/wikispeedia/evidence/1-9.json) · [Read original source](https://dlab.epfl.ch/wikispeedia/wpcd/wp/m/Music.htm)

## Use Loom from an agent

Loom visualises and edits graph documents in your app. It is not a hosted graph database or an RDF query engine. The public examples are read-only data; the hosted MCP demo still requires guest consent.
